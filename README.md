# 作業回饋小幫手 · Asistente de corrección

給華語老師用的小工具：貼上學生寫的中文句子，產生**中西對照**的作業回饋草稿，老師看過、改過，再傳給學生。

*Herramienta para profesores de chino: pega las oraciones de tus alumnos y obtén un borrador de corrección en chino y español, para revisarlo y enviarlo.*

---

## 這個工具做什麼

- 把學生的句子組成一段完整的「批改指令」，貼到任何 AI（ChatGPT、Gemini、Claude 都可以）
- 把 AI 的回答貼回來，自動整理成可編輯的草稿
- 每個錯誤附**西語說明**和**中文說明**，最後有一句鼓勵
- 一鍵複製要傳給學生的訊息
- 記錄每位學生常犯的錯誤，下次批改時自動提醒 AI 特別留意，也能產生針對弱點的複習題指令

整個工具只有一個網頁檔（`index.html`），不需要安裝、不需要後台，也不需要 API 金鑰。

## 怎麼用

1. **貼句子**：填學生名字（可不填主題），貼上句子，一行一句，按「組好指令並複製」。
2. **問 AI**：把複製的指令貼到任何 AI，等它回答。
3. **貼回來**：把 AI 的整段回答貼回「② 把 AI 的回答貼回來」，按「整理成草稿」。
4. **檢查修改**：逐句檢查。不同意 AI 的修改，就按「不採用這個修改」，會還原成學生原本的寫法。
5. **傳給學生**：按「複製訊息」。滿意的話按「存進學生紀錄」。

## 設計重點：不讓 AI 亂改

指令裡寫了嚴格的規則，避免 AI 把本來正確的句子改掉：

- 只改**明確的錯誤**（文法、搭配、錯字、語序），意思清楚又沒錯的句子就算正確
- 不為了「更自然」而改，不改標點，不轉換簡繁體，不換掉學生選的詞
- 沒把握的地方不改，只寫一句「老師參考」，這句不會傳給學生

## 資料存在哪裡

學生紀錄只存在**使用者自己瀏覽器**（localStorage），不會上傳到任何伺服器。

- 換電腦或清除瀏覽資料前，請到「備份」頁**匯出備份檔**
- 匯入備份時，會和現有資料合併，不會覆蓋

## 使用方式

- 直接用瀏覽器打開 `index.html`
- 或開啟 GitHub Pages（Settings → Pages → Branch: `main` / root），就能用網址在手機上使用
